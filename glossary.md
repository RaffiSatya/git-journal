# Glosarium

| Istilah | Arti |
|---|---|
| Repository | Folder project yang riwayatnya dicatat Git |
| Commit | Snapshot project pada satu titik waktu |
| Branch | Jalur kerja paralel |
| venv | Python terisolasi khusus satu project |
| merge | Menggabungkan branch ke main |
| conflict | Keadaan ketika 2 branch tidak sinkron (perubahan di 2 branch di line sama) |
| staging | Fase dimana kita sudah melakukan git add |
