# Project 01 — `hello-terminal`

**Tanggal:** 2026-10-27 · **Repo:** https://github.com/RaffiSatya/hello-terminal

## Apa yang dibangun
CLI Python yang merapikan folder data GIS ke subfolder per kategori (Vektor, Raster, LiDAR, QGIS, dst.), lengkap dengan mode `--dry-run`.

## Konsep baru
- **Path dengan spasi/petik:** wajib dibungkus `"..."`. Spasi memecah argumen, dan `'` di PowerShell dibaca sebagai awal string.
- **venv:** dibuat sekali (`python -m venv .venv`), tapi harus di-activate di setiap jendela terminal baru, karena aktivasi hanya mengubah PATH terminal itu.
- **Urutan setup project:** buat venv → activate → `pip install -r requirements.txt`. Kalau install sebelum activate, library masuk ke Python global.
- **requirements.txt:** mengunci versi library supaya orang lain mendapat versi yang sama.
- **Pure function:** `get_category` hanya membaca nama file, tidak melihat isi folder.
- **Idempotent:** program yang mengubah file harus aman dijalankan berkali-kali. Tanpa `if item.is_dir(): continue`, run kedua crash dengan `shutil.Error: Cannot move a directory into itself`.

## Kesalahan yang saya buat (dan pelajarannya)
- Mengira `get_category` hasilnya "Vektor" karena file sudah diorganize. Ternyata karena `.suffix.lower()`.
- Menulis `pip install` sebelum membuat venv.
